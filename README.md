# Nexus Form – Echo Personnalisé (AI)

[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

**Full-stack AI-powered dynamic form** developed for **SFEIR’s challenge – La Nuit de l’Info 2025**.

---

## 🌐 Project Overview

**Nexus Form – Echo Personnalisé** transforms a classic contact form into an **intelligent interaction portal**.  
The form dynamically adapts to user intent, delivers **personalized AI-driven feedback**, and ensures a modern, secure, and accessible user experience.

---

## 🎯 Features

- Dynamic form adapting to user mission:
  - 📞 Contact
  - 💰 Donation
  - 🛡️ Volunteer Engagement
  - ❓ Information Request
- AI-generated personalized confirmation messages
- Fully responsive design (desktop, tablet, mobile)
- Secure backend with input validation and spam protection
- Accessibility-friendly UX

---
## 🛠️ Tech Stack

- **Frontend:** React, TypeScript  
- **Backend:** Node.js, Express  
- **AI Integration:** Hugging Face LLM via OpenAI-compatible SDK  
- **Styling:** Responsive modern UI  
- **Security:** dotenv for sensitive environment variables  
---

## 🚀 Getting Started

### 1. Clone the repository
git clone https://github.com/USERNAME/nexus-echo-form.git
cd nexus-echo-form

2. Install dependencies Run the application
# Frontend
npm install
cd ../frontend
npm run dev
# Backend
cd ../backend
npm install
cd backend
npm run start

3. Set up environment variables
Create a .env file in the backend folder
